# Far Ride Viewer

[English version](README.md)

Модульный плагин просмотра изображений для Far Manager 3.x. Поддерживаемые изображения открываются в отдельном нативном окне Windows; декодирование выполняют независимо загружаемые DLL-кодеки.

В основе окна просмотра и работы с изображением лежит функциональность проекта [FarQoiViewer](https://github.com/zara6502/far-qoi-viewer). Декодирование вынесено в отдельные модули, взаимодействующие с плагином через версионируемый C ABI.

## Возможности

- Нажатие `F3` на поддерживаемом файле открывает его в просмотрщике.
- Формат определяется функцией `Probe` соответствующего кодека. Расширение файла влияет только на приоритет проверки и не заменяет проверку содержимого.
- DLL-кодеки загружаются из каталога `Codecs`, расположенного рядом с `FarRideViewer.dll`.
- Чтение файлов и декодирование выполняются в фоновом потоке.
- Сохраняются пропорции изображения.
- Поддерживаются режимы вписывания в окно и отображения 1:1.
- Масштабирование выполняется колёсиком мыши и клавишами `+` / `-`.
- Перемещение изображения — стрелками; центрирование — клавишей `Home`.
- Прозрачность RGBA отображается с альфа-композитингом поверх выбранного фона.
- Доступны шахматный, чёрный и белый фоны.
- Экран `F1` показывает версию просмотрщика, версию Codec API и список зарегистрированных кодеков.
- При ошибках чтения, декодирования или проверки результата отображается диагностическая информация.
- Одновременно открывается не более одного окна просмотрщика; повторный вызов переводит существующее окно на передний план.
- Файлы, которые не распознаны установленными кодеками, остаются в обработке Far Manager.

## Включённые кодеки и поддерживаемые форматы

В репозитории находятся следующие DLL-кодеки. Они собираются как отдельные модули и обнаруживаются при запуске.

| DLL | Кодек | Расширения / форматы |
|---|---|---|
| `qoi.dll` | QOI / QOIMT | `.qoi` — стандартный QOI (RGB/RGBA) и вариант QOIMT проекта |
| `pcx.dll` | PCX | `.pcx` |
| `stb_image.dll` | stb_image | `.bmp`, `.tga`, `.jpg`, `.jpeg`, `.png`, `.gif` |
| `zx_spectrum.dll` | ZX Spectrum SCR | `.scr` — файлы экрана размером 6144 и 6912 байт |

### Особенности форматов

- **QOI / QOIMT:** файлы QOI распознаются по сигнатуре `qoif`. Кодек также поддерживает вариант QOIMT проекта с независимо декодируемыми полосами.
- **PCX:** распознаётся по заголовку PCX и декодируется отдельным модулем.
- **BMP, TGA, JPEG, PNG, GIF:** декодируются включённой реализацией `stb_image`. Для анимированного GIF отображается только первый кадр; воспроизведение анимации не реализовано. Поддержка JPEG ограничена возможностями stb_image: JPEG с арифметическим кодированием и 12-битный JPEG не поддерживаются.
- **ZX Spectrum SCR:** оба варианта имеют разрешение 256×192. Файл размером 6144 байта содержит только bitmap (монохромное отображение); файл размером 6912 байт содержит bitmap и область атрибутов размером 768 байт (цветное отображение). У SCR нет сигнатуры, поэтому кодек распознаёт формат по точному размеру файла. Анимация FLASH не реализована.

Все кодеки возвращают просмотрщику пиксели в формате RGBA8, строки расположены сверху вниз.

## Управление

| Клавиша / действие | Результат |
|---|---|
| `0` | Вписать изображение в окно |
| `1` | Масштаб 100% (1:1) |
| `+` / `-` | Увеличить / уменьшить масштаб |
| Колёсико мыши | Изменить масштаб |
| Стрелки | Переместить изображение |
| `Home` | Центрировать изображение |
| `Space` / левая кнопка мыши | Переключить режим Fit / zoom |
| `F1` | Показать / скрыть сведения о просмотрщике и зарегистрированных кодеках |
| `Esc` | Закрыть просмотрщик (также закрывает экран F1) |
| `w` | Белый фон |
| `b` | Чёрный фон |
| `c` | Шахматный фон |

На экране `F1` список кодеков можно прокручивать стрелками вверх/вниз или колёсиком мыши. Повторное нажатие `F1` возвращает к изображению.

## Открытие изображения из командной строки Far

Используй префикс команды плагина `ride:`, после которого указывается путь к изображению:

```text
ride: C:\\path\\to\\image.qoi
ride: "C:\\path with spaces\\image.png"
```

Также можно выбрать поддерживаемый файл в панели Far Manager и нажать `F3`.

## Сборка

### Требования

- Windows
- [MSYS2 UCRT64](https://www.msys2.org/) с MinGW-w64 GCC
- CMake 3.20 или новее
- Ninja
- Git
- Исходный код Far Manager, содержащий `far/plugin.hpp`

Проект использует C++17 и заголовок SDK Far Manager из дерева исходников.

Предполагается, что исходники Far Manager находятся рядом с репозиторием в каталоге `../FarManager`:

```bash
git clone --depth 1 https://github.com/FarGroup/FarManager.git ../FarManager

cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DFAR_SOURCE_DIR="$PWD/../FarManager"

cmake --build build
ctest --test-dir build --output-on-failure
```

В результате сборки создаются `FarRideViewer.dll` и DLL-кодеки в `build/Codecs/`.

## Установка

Скопируй DLL плагина и каталог кодеков, сохранив структуру:

```text
Plugins/
\`-- FarRideViewer/
    |-- FarRideViewer.dll
    \`-- Codecs/
        |-- qoi.dll
        |-- pcx.dll
        |-- stb_image.dll
        \`-- zx_spectrum.dll
```

После установки или замены DLL перезапусти Far Manager. Список кодеков загружается один раз за сеанс Far Manager.

## API кодеков

Модули кодеков реализуют **Ride Codec API v1**. Host ожидает четыре экспортируемые функции:

- `RideCodecGetInfo`
- `RideCodecProbe`
- `RideCodecDecode`
- `RideCodecFreeImage`

API определяет метаданные кодека, проверку содержимого файла, декодирование в top-down RGBA8, передачу ошибок и освобождение памяти изображения самим модулем, который её выделил.

- [Справочник Codec API (русский)](docs/CODEC_API.ru.md)
